#  Basic Data Sorting & Filtering

## Objective
Practice basic data exploration by sorting and filtering a retail sales dataset to answer business questions.

## Tools Used
- Microsoft Excel
- Retail Sales Dataset

## Work Completed
- Organized and explored 150 sales records.
- Applied multiple filters to the dataset.
- Sorted sales data for comparison.
- Filtered records by region, category, and sales value.
- Answered five business questions using the dataset.

## Deliverables
- Excel workbook containing raw data.
- Filtered dataset.
- Five answered business questions.
- Instructions for sorting and filtering.

## Key Learning
Learned how to use Excel sorting and filtering features to explore datasets and identify useful business insights.
